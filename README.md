# רשימת קניות משותפת

## הגדרת השרת

יש להגדיר בשרת את משתני הסביבה `TURSO_URL`, `TURSO_TOKEN` ו-`AUTH_SECRET`.
בפיתוח מקומי ניתן להגדיר אותם בקובץ `server/.env`. בפריסה יש להגדיר אותם גם
בסביבת השרת, למשל ב-Environment של Render.

`AUTH_SECRET` חייב להיות ערך סודי ואקראי באורך של לפחות 32 בתים. ליצירת ערך
ניתן להריץ:

```sh
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

יש לשמור את אותו הסוד בין הפעלות ופריסות. שינויו מנתק את כל החשבונות. אין
לשתף אותו או לשמור אותו בקוד המקור.

## מסד הנתונים

לאחר גיבוי מסד הנתונים, יש להריץ ידנית פעם אחת את
`server/migrations/001_users.sql` על מסד ה-Turso הקיים, לפני הפעלת גרסת השרת
החדשה. ההעברה יוצרת את שלושת החשבונות ומשייכת את הפריטים הקיימים לחשבון
שחר ודן. אין להריץ אותה שוב לאחר שהצליחה. לאחר הגדרת `AUTH_SECRET` יש לפרוס
יחד את השרת והלקוח המעודכנים.

## התחברות

ההתחברות נשמרת בדפדפן ללא תוקף מוגבל. הסיסמה אינה נשמרת בדפדפן; האסימון
נשמר ב-localStorage ולכן יש להשתמש ב-HTTPS ולהגן על האפליקציה מפני XSS.
התנתקות מסירה את האסימון מהדפדפן הנוכחי בלבד. שינוי סוד החתימה מנתק את כל
המכשירים. החשבונות מוגדרים מראש ואין אפשרות הרשמה מתוך האפליקציה.
